# IREME Real Estate

Public website for IREME Real Estate (Kigali, Rwanda). Standard Vite + React SPA
with Tailwind CSS v4. All content (properties, services, blog posts, FAQs, company
contact info) lives in JSON files inside the project — no backend required.

Adding or editing a property = editing one JSON file (`src/data/properties.json`).
The site rebuilds and shows it.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```
